# Mobile Testing

## Практический опыт

В рамках тестового задания на позицию QA Engineer было выполнено функциональное тестирование мобильного приложения.

Во время проверки использовались предоставленные тест-кейсы.

Выполненные задачи:

- выполнение тест-кейсов;
- анализ поведения приложения;
- сравнение Actual Result и Expected Result;
- оформление баг-репортов;
- определение Severity;
- определение Priority.

> Expected Result был указан в тестовой документации, предоставленной вместе с заданием.
