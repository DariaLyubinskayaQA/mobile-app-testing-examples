Практический опыт

В рамках тестового задания на позицию QA Engineer было выполнено тестирование мобильного приложения с использованием предоставленных тест-кейсов.

Выполненные работы

прохождение тест-кейсов;
анализ фактического поведения приложения;
сравнение фактического результата с ожидаемым, указанным в тестовой документации;
оформление баг-репортов;
определение Severity и Priority;
документирование окружения и шагов воспроизведения.

Примечание

Ожидаемые результаты были предоставлены в составе тестовой документации. Все баг-репорты оформлены на основании выявленных расхождений между ожидаемым и фактическим поведением приложения.
